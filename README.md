# Edifício Abismo

Jogo de terror no estilo Elevator Action: um policial precisa descer os 100 andares de um prédio em ruínas.

**Jogar:** abra o `index.html` publicado no GitHub Pages.

## Modos
- **1 jogador**
- **2 jogadores no mesmo aparelho**
- **Online:** um jogador toca em *Criar sala* e passa o código de 4 letras; o outro toca em *Entrar na sala* e digita o código.

O modo online conecta os dois aparelhos diretamente (WebRTC, via PeerJS). Não precisa de servidor próprio.
